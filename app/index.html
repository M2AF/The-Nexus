YOUR CONNECTED LIBRARIES

Owned games, together.

The Nexus reads the libraries you already synced in GOG Galaxy, including Steam, GOG, Epic, and Xbox. No new sign-in is needed when that cache is available. The itch.io app cache is read separately for installed games and indexed purchase/bundle records. Wavedash browser games are in the Web tab.

The import is read-only and uses Galaxy's library records. Update or connect accounts in Galaxy, then sync here. Xbox library records may include console, shared, or subscription titles; being listed does not guarantee PC compatibility or a permanent purchase.

itch.io

No local cache? Import a JSON file with a games array. Each entry needs provider (steam, gog, epic, xbox, itch, battlenet), id, and name. Steam GetOwnedGames JSON is also supported. Only library metadata is imported; no launch commands or credentials.
